# Tools And Plugins

This file tracks known or possible tool categories for this workspace. Availability depends on the current environment.

## GitHub

- Use when available for repositories, pull requests, issues, and checks.
- Do not use for unrelated external browsing or non-GitHub systems.

## Browser Use

- Use when available for localhost UI checks and manual QA.
- Do not assume it is available in every environment.

## Documents

- Use when available for `.docx` artifacts.
- Do not use for plain Markdown edits.

## Presentations

- Use when available for `.pptx` artifacts.
- Do not use for non-presentation documents.

## Spreadsheets

- Use when available for `.xlsx` and `.csv` artifacts.
- Do not use for unrelated text or code changes.
