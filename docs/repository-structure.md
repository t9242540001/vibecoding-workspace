# Repository Structure

This repository is the shared infrastructure workspace for Vibe Coding.

## Paths

- `AGENTS.md` - root instructions for Code Agents in this repository.
- `.codex/` - Codex-specific operating notes and future packaging space.
- `standards/` - shared standards and system instruction mirror.
- `skills/` - canonical shared skills.
- `templates/` - starter templates for product repositories.
- `tools/` - tool and plugin notes.
- `rules/` - shared rule documents.
- `scripts/` - workspace utility scripts.
- `docs/` - supporting documentation.
- `workspace-index.md` - root navigation file.
