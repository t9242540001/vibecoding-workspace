# Codex Instructions

## Before Work

- Run `git status --short`.
- Read `AGENTS.md`, `CLAUDE.md`, and `knowledge/INDEX.md`.
- If git is unavailable, report it and stop.

## Before Edits

- Inspect relevant files before editing.
- Read relevant `knowledge/*.md` files selected through `knowledge/INDEX.md`.

## During Work

- Edit only files inside the task scope.
- Keep changes small and project-specific.
- Do not commit secrets, `.env`, tokens, credentials, or private keys.

## Verification

- Run relevant verification if commands are known.
- If commands are unknown or cannot run, report the reason.

## Commit And Push

- Commit and push only when changed files match task scope, unless project policy says otherwise.
